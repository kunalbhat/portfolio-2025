# Find Kunal

A pixel town to explore, with me hidden in it. Served at `/find`.

This folder is a **build output**, committed so the site stays build-free like `desk/`. The source lives on the `experiment/find-kunal` branch (Vite + TypeScript, everything drawn in code). To update:

    git checkout experiment/find-kunal
    npm install && npm run build
    # then on main: replace find/index.html and find/assets/ with dist/index.html and dist/assets/
